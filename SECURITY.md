## Reportar una vulnerabilidad

Por favor, **no abras un issue público** para vulnerabilidades de seguridad.
Usa la opción [Report a vulnerability](https://github.com/AlexandreColl/PixelArtEditor/security/advisories/new)
de GitHub para enviarla de forma privada. Intentaremos responder en un plazo de 7 días.

## Claves de API

Las claves de los proveedores de IA se guardan únicamente en el almacenamiento local de la aplicación
y se envían directamente al proveedor seleccionado. Nunca subas claves al repositorio ni las incluyas en issues o PRs.
